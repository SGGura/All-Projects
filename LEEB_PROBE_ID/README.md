# Зонд твердомера Либа: сигнал и опознавание типа

Разрез зонда, сигнал катушки и опознавание типа зонда по резистору в
разъёме. Полная версия с интерактивными схемами:
https://claude.ai/code/artifact/4c838998-a421-4140-bcb7-a3d77e65b7a2

## Устройство зонда

Пружина взводит ударное тело (боёк) с твердосплавным или алмазным шариком
на конце и с запрессованным постоянным магнитом внутри. На направляющей
трубке, в точке, где магнит проходит и туда, и обратно, намотана катушка
индуктивности — единственный измерительный элемент; активной электроники
внутри зонда нет.

```
   [взвод / спуск]
        │
     пружина (3)  ~~~~~
        │
   боёк с магнитом (1)
        │
   ┌─── катушка (2) ───┐   → к усилителю / АЦП
        │
   индентор (шарик WC / алмаз)
        ▼
   поверхность детали
```

## Сигнал с катушки

Движущийся магнит наводит в катушке ЭДС, пропорциональную скорости бойка:
`e = -N·dΦ/dt ∝ v`. При подлёте к поверхности катушка даёт импульс с
амплитудой `V_i` (скорость удара); после удара и отскока — второй импульс,
меньшей амплитуды `V_r` (скорость отскока), примерно через 1–2 мс.

```
HL = 1000 × V_r / V_i
```

## Опознавание типа зонда

У Либа не один зонд, а семейство — они отличаются энергией удара, диаметром
и материалом шарика под разную массу/толщину/твёрдость детали. Формула
`HL = 1000·V_r/V_i` одна, но чувствительность катушки и таблица пересчёта в
HRC/HB/HV у каждого типа свои. Если прибор поддерживает несколько зондов
через один разъём, в разъём впаян резистор-код `R_id`; электронный блок
измеряет его делителем + АЦП и по таблице выбирает калибровочную кривую.

```
Зонд (R_id в разъёме) → делитель + АЦП блока → таблица типов → калибровка (энергия, шарик) → HL → HRC/HB/HV
```

Опознавание типа зонда происходит один раз при подключении и не связано
с самим измерением удара.

## Семейство зондов

Энергия удара и материал шарика — паспортные параметры каждого типа
(ГОСТ Р ИСО 16859 / ASTM A956). Номиналы `R_id` — иллюстративный пример:
у разных производителей код зонда может быть построен иначе (резистор,
EEPROM в разъёме, механическая кодировка).

| Тип   | Энергия удара | Шарик         | Применение                              | R_id* |
|-------|----------------|---------------|------------------------------------------|-------|
| D     | 11 Н·мм        | ТВС, ⌀3 мм    | общего назначения, самый ходовой         | 1.0 кОм |
| DC    | 11 Н·мм        | ТВС, ⌀3 мм    | тонкий корпус — тесные места             | 1.2 кОм |
| D+15  | 11 Н·мм        | ТВС, ⌀3 мм    | удлинённый — пазы, отверстия             | 1.5 кОм |
| DL    | 11 Н·мм        | ТВС, ⌀3 мм    | узкий, для глубоких отверстий            | 1.8 кОм |
| C     | 2.7 Н·мм       | ТВС, ⌀3 мм    | лёгкий удар — тонкие/малые детали        | 2.2 кОм |
| G     | 90 Н·мм        | ТВС, ⌀5 мм    | тяжёлые отливки и поковки                | 2.7 кОм |
| E     | 11 Н·мм        | алмаз, ⌀3 мм  | очень твёрдые материалы (закалка, керамика) | 3.3 кОм |

\* иллюстративные номиналы для примера схемы, не отраслевой стандарт.

## Алгоритм в приборе

1. При подключении зонда измерить `R_id` → определить тип зонда (один раз).
2. Ждать удар (порог по фронту сигнала катушки).
3. Оцифровать сигнал катушки быстрым АЦП в окне ~5 мс.
4. Найти пики `V_i` и `V_r`. Если не найдены (двойной удар/срыв) — отбросить
   замер и повторить.
5. Посчитать `HL = 1000·V_r/V_i`, пересчитать по калибровочной кривой типа
   зонда → HL / HRC / HB / HV.

## Практические замечания

- **Угол удара** — гравитация подгоняет/тормозит боёк в зависимости от
  направления удара (вниз/вверх/вбок); без поправки на угол показания
  смещаются на десятки единиц HL.
- **Масса и опора детали** — слишком лёгкая или неопёртая деталь поглощает
  часть энергии удара как целое, занижая результат; у каждого типа зонда
  есть паспортный минимум массы/толщины.
- **Перпендикулярность и чистота поверхности** — удар не строго
  перпендикулярно оси или грязная/шероховатая поверхность искажают отскок
  сильнее, чем ошибка измерения самих V_i/V_r.
- **Двойной удар** — если боёк ударяется о поверхность второй раз, не выйдя
  из катушки, получается ложный второй пик; такой замер нужно отбраковывать,
  а не выдавать как результат.

Схема иллюстративная: реальные приборы разных производителей могут
кодировать тип зонда иначе (например, EEPROM в разъёме вместо резистора) —
см. паспорт конкретного твердомера.
