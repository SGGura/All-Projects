# Опознавание геркон-датчиков по кодирующему резистору

Схема съёма сигнала с геркона (reed switch) и определения его типа по номиналу
резистора, впаянного внутри датчика. Полная версия с интерактивными схемами:
https://claude.ai/code/artifact/4c838998-a421-4140-bcb7-a3d77e65b7a2

## Идея

Голый геркон даёт только «сухой контакт» (замкнуто/разомкнуто). Чтобы одним
входом АЦП обслуживать несколько типов датчиков (дверь, окно, крышка
тампера) и вдобавок отличать обрыв/КЗ шлейфа от реального срабатывания,
внутрь датчика ставят резистор конкретного номинала. Контроллер измеряет не
цифровой уровень, а напряжение на делителе — и по таблице порогов определяет
сразу тип датчика и состояние его контактов.

## Тракт сигнала

```
Геркон + кодирующий R → делитель (R_pu / R_шлейф) → АЦП МК → декодер (таблица порогов) → тип + состояние
```

## Схема делителя

```
Vcc (3.3 В)
   │
  R_pu (10 кОм)
   │
   ├──────────────► вход АЦП МК
   │
   ▼  шлейф (Loop+)
 ┌─────────────────────────┐
 │   геркон ──╮             │   R_геркон = 0 Ом (замкнут, есть магнит)
 │            R∥            │   R_геркон = ∞   (разомкнут, магнита нет)
 │   ────────╯             │
 └─────────────────────────┘
   │
  R_EOL (на плате контроллера)
   │
  GND
```

`R∥` стоит в корпусе датчика параллельно контактам геркона и вместе с
`R_EOL` образует нижнее плечо делителя. Номиналы `R∥`/`R_EOL` — это код типа
датчика; обрыв или КЗ всего шлейфа дают два дополнительных, чётко отличимых
уровня напряжения.

## Формулы

```
U_adc      = Vcc · R_шлейф / (R_pu + R_шлейф)
R_шлейф    = R_EOL + (R_геркон ∥ R∥)
R_геркон   = 0    — контакт замкнут (есть магнит)
R_геркон   = ∞    — контакт разомкнут (магнита нет)
```

## Таблица порогов (пример: Vcc = 3.3 В, R_pu = 10 кОм, АЦП 12 бит)

| Код АЦП     | U, тип.  | R_шлейф   | Тип датчика     | Состояние             |
|-------------|----------|-----------|-----------------|------------------------|
| 0 – 185     | ≈0.00 В  | 0 Ом      | —               | Авария: КЗ             |
| 186 – 682   | ≈0.30 В  | 1.0 кОм   | Дверь           | Норма (замкнут)        |
| 683 – 1151  | ≈0.80 В  | 3.2 кОм   | Дверь           | Тревога (разомкнут)    |
| 1152 – 1807 | ≈1.06 В  | 4.7 кОм   | Окно            | Норма (замкнут)        |
| 1808 – 2383 | ≈1.86 В  | 12.9 кОм  | Окно            | Тревога (разомкнут)    |
| 2384 – 2882 | ≈1.98 В  | 15 кОм    | Крышка (тампер) | Норма (замкнут)        |
| 2883 – 3702 | ≈2.67 В  | 42 кОм    | Крышка (тампер) | Тревога (разомкнут)    |
| 3703 – 4095 | ≈3.30 В  | ∞ (обрыв) | —               | Авария: обрыв линии    |

Номиналы взяты из ряда E12 (1.0k / 2.2k, 4.7k / 8.2k, 15k / 27k).

## Алгоритм прошивки

1. Взять N выборок АЦП, усреднить (фильтр дребезга геркона, 1–10 мс).
2. Если `U ≈ Vcc` → авария «обрыв линии».
3. Если `U ≈ 0` → авария «короткое замыкание».
4. Иначе найти диапазон в таблице порогов → тип датчика + состояние.
5. Если код не попал ни в один диапазон → «неизвестный/неисправный датчик».
6. Подтвердить смену состояния 2–3 совпавшими подряд выборками, опубликовать
   событие; повторить цикл (~50 мс).

```c
typedef struct {
    uint16_t adc_lo, adc_hi;
    sensor_type_t type;      /* SENS_DOOR, SENS_WINDOW, SENS_TAMPER, SENS_NONE */
    contact_state_t state;   /* ST_CLOSED, ST_OPEN, FAULT_SHORT, FAULT_OPEN     */
} zone_profile_t;

static const zone_profile_t table[] = {
    {    0,  185, SENS_NONE,   FAULT_SHORT },
    {  186,  682, SENS_DOOR,   ST_CLOSED   },
    {  683, 1151, SENS_DOOR,   ST_OPEN     },
    { 1152, 1807, SENS_WINDOW, ST_CLOSED   },
    { 1808, 2383, SENS_WINDOW, ST_OPEN     },
    { 2384, 2882, SENS_TAMPER, ST_CLOSED   },
    { 2883, 3702, SENS_TAMPER, ST_OPEN     },
    { 3703, 4095, SENS_NONE,   FAULT_OPEN  },
};

zone_event_t classify_zone(uint16_t adc_code) {
    for (size_t i = 0; i < ARRAY_LEN(table); i++)
        if (adc_code >= table[i].adc_lo && adc_code <= table[i].adc_hi)
            return (zone_event_t){ table[i].type, table[i].state };
    return (zone_event_t){ SENS_NONE, FAULT_OPEN };
}
```

## Практические замечания

- **Дребезг контактов** — геркон дребезжит 1–10 мс после переключения;
  подтверждайте состояние усреднением нескольких выборок АЦП, а не первой же.
- **Допуски резисторов** — на плотной сетке порогов 5%-ные резисторы съедают
  почти весь запас; берите `R∥`/`R_EOL` с допуском 1% или разносите номиналы
  кратно ×2–×3.
- **Защита входа АЦП** — на длинном шлейфе поставьте ограничительный резистор
  и супрессор/стабилитрон от статики и наводок.
- **Термостабильность** — при плотных диапазонах `R_pu` и резисторы датчиков
  берите одного температурного коэффициента.

Это типовой приём охранной сигнализации, известный как supervised zone /
EOL-резистор. Номиналы и пороги — пример для расчёта под конкретное железо.
